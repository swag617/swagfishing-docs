# Support

## Reporting Bugs

Found a bug? Please report it on GitHub so it can be tracked and fixed.

**When reporting a bug, include:**
* Your server version (e.g., Paper 1.21.4 build 123)
* SwagFishing version (visible in the plugin list or startup log)
* A clear description of what happened vs. what you expected
* Relevant console errors or stack traces (paste the full error, not just the first line)
* Steps to reproduce the issue

**Where to report:** Open an issue on the SwagFishing GitHub repository.

## Asking Questions

Before asking, check:
1. The [FAQ](faq.md) — covers the most common issues
2. The relevant documentation page for your topic
3. Existing GitHub issues (someone may have already asked)

If you still need help, open a GitHub issue with your question or reach out through the community channels listed on the repository.

## Contributing Fish Ideas

Have an idea for a great custom fish? Submit it as a GitHub issue with the label "fish idea". Include:

* Fish name and description
* What biome/time/weather it should spawn in
* Suggested rarity
* Any special mechanics you envision

Fish ideas are welcomed and reviewed for addition to the base fish pool.

## Contributing to Development

SwagFishing is proprietary software, but feedback and suggestions are always appreciated. If you're a developer and want to discuss the project, reach out through the GitHub repository.

## Useful Information for Any Support Request

* `/fish stats` — shows your current level, XP, essence, and fish counts
* `/fish reload` — use this before reporting config issues to confirm changes applied
* Check console output at startup for "Loaded X fish" confirmations
* The database file is at `plugins/SwagFishing/fishing.db`
* Config file is at `plugins/SwagFishing/config.yml`
