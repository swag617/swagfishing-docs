# Welcome to SwagFishing

> **SwagFishing** is a feature-rich, highly customizable fishing plugin for Minecraft servers running Paper/Spigot 1.21+

## What Makes SwagFishing Special?

SwagFishing transforms the vanilla Minecraft fishing experience into an engaging progression system with:

* **Custom Fish System** - Over 100+ unique fish across 5 rarity tiers
* **Fish Codex** - Collection-based discovery and tracking system
* **Fish Bag** - Persistent fish storage with paginated GUI
* **Sell Shop** - Sell your catches directly through a GUI
* **Gutting System** - Convert fish into essence currency
* **Skill Tree** - 6 unlockable passive skills, upgraded with essence and skill points
* **Totems** - 10 powerful persistent fishing buffs unlocked by level
* **Bait** - 15 consumable items across 4 tiers for temporary boosts
* **Dynamic Events** - Server-wide fishing bonuses (Fishing Frenzy, Rare Tide, Essence Surge)
* **Tournaments** - Competitive fishing events with leaderboards
* **Deliveries** - Fishing quests with essence rewards
* **Lore Schemes** - Template system for automatic fish lore generation
* **Web Editor** - Full-featured web interface for managing custom fish

## Core Philosophy

### Codex = Cosmetic Collection
The Fish Codex is purely for **showing off** your achievements. Catching rare fish is rewarding, but the Codex itself grants no gameplay advantages. Power comes from the Skill Tree and progression systems.

### Skills = Gameplay Power
Passive buffs come from the **Skill Tree**, unlocked through grinding and player choice. This ensures that:
* Power comes from effort, not luck
* Players can customize their fishing style
* Progression is always guaranteed

### No Pay-to-Win, No RNG Walls
Everyone has access to the same fishing opportunities. Success comes from:
* Time invested (XP and levels)
* Strategic skill choices
* Knowledge of fish spawns and conditions

## Feature Highlights

### Dynamic Fishing
Fish spawn based on:
* **Biome** - Ocean, River, Swamp, Jungle, etc.
* **Time** - Dawn, Day, Dusk, Night
* **Weather** - Clear, Rain, Thunder
* **Y-Level** - Altitude requirements

### Fish Codex
A discovery system that tracks:
* Which fish you've caught
* Completion percentage
* Individual fish statistics
* Rarity distribution

### Skill Tree
6 unlockable passive skills offering:
* XP multipliers (XP Boost, up to +50%)
* Essence multipliers (Essence Boost, up to +50%)
* Rarity improvements (Rare Finder, up to 3× weight for SAPPHIRE+)
* Economy bonuses (Market Expert, +10% sell price per level)
* Catch rate improvements (Lucky Cast, +5% custom fish chance per level)
* Delivery rewards (Delivery Expert, +25% delivery essence per level)

### Web Editor
A full-featured web interface for server admins:
* Create and edit custom fish visually
* Live Minecraft-style tooltip preview
* Lore schemes management
* No YAML editing required
